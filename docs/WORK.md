# K-gov-agent 첫 구현

기준일: 2026-11-15 (Asia/Seoul). 목표는 ChatGPT Work와 유사한 대화 중심의 업무 위임·진행·개입·결과 검토 경험이다. 현재 첫 버전이며 전체 Work 기능 복제를 완료한 것은 아니다.

## 사용 흐름

1. 새 대화에서 요청하거나 프로젝트를 만들어 작업 지침을 입력한다.
2. 입력창의 + 버튼으로 자료를 연결한다. 프로젝트 자료는 해당 프로젝트의 새 작업에 자동 포함된다.
3. Work 모드로 보고서·회의록·비교 문서 등을 요청한다. 짧은 질문은 대화 모드를 사용할 수 있다.
4. 실제 모델 출력과 작업 기록이 표시된다. 실행 중에는 텍스트 추가 요청을 보내거나 중지할 수 있다.
5. 정보가 필요하면 에이전트가 질문하고 입력을 기다린다. 답변하면 같은 작업을 이어간다.
6. 생성 문서를 오른쪽에서 검토하고 다운로드한다. 수정 요청을 같은 대화에 보내면 같은 파일명으로 새 버전을 저장한다.
7. 브라우저를 새로 열어도 URL의 대화 ID로 대화·작업·문서 버전을 복원한다.

대화 검색은 불러온 최근 대화 제목을 대상으로 한다. 새 대화 단축키 N은 입력 중이 아닐 때 동작한다. 자료실·사용 승인 관리도 같은 작업 공간에서 접근한다. 프로젝트는 현재 본인 전용이며 다른 계정과 공유하지 않는다.

## 현재 지원 범위

| 항목 | 구현 |
| --- | --- |
| 화면 | 왼쪽 프로젝트·대화 탐색, 중앙 대화·진행·입력창, 오른쪽 문서 미리보기 |
| 프로젝트 | 생성·이름/지침 수정·자료 연결/해제·프로젝트별 대화 |
| 모델 | DeepInfra의 기존 DeepSeek 모델, 실제 스트리밍 출력. 다른 OpenAI 호환 주소로 설정 가능 |

| 도구 | create_document(Markdown), ask_user(질문 후 대기) |

PDF·HWP·HWPX·DOCX·이미지 OCR, DOCX/PPTX/XLSX 결과물, 웹 검색·내부 시스템 커넥터·브라우저 제어·예약 작업은 아직 지원하지 않는다. CSV 입력은 텍스트 자료로 읽으며 스프레드시트 계산 엔진이나 분석 코드 실행기는 아니다. 새 첨부 자료는 새 작업에 연결한다. 진행 중인 작업의 개입은 현재 텍스트 추가 요청이며 질문 대기 중 새 파일 업로드/교체는 별도 후속 범위다.

## 실행 구조와 복구 의미

FastAPI 단일 프로세스 안에 2개 슬롯의 비동기 실행기를 둔다. 브라우저 연결과 작업 수명은 독립적이다. 모델은 스트리밍하고 서버가 부분 출력과 상태를 DB에 저장하며 웹은 약 1초 간격으로 구독 상태를 갱신한다. 진행 표시는 실제 통신·파일 읽기·도구 실행 이벤트에서 생성한다. 모델의 비공개 추론을 표시하지 않는다.

DB 큐는 재시작 후에도 남는다. 비정상 종료 때 running이던 작업은 시작 시 failed/SERVER_RESTARTED로 표시하며 모델을 자동 재호출하지 않는다. 정상 종료 시 실행 중 작업은 취소되고, 대기·질문 상태는 유지된다. 지금은 API 1프로세스 전용이다. 여러 worker/서버 운영과 lease 기반 분산 큐는 후속 범위다.

대화별 실행은 한 개씩 허용하며, 새 요청은 request_id와 요청 해시로 중복 실행을 막는다. 같은 ID로 다른 내용을 제출하면 거부한다. 한 번의 실행은 최대 180초·모델 8라운드·라운드당 출력 6천 토큰으로 제한한다. 실제 토큰/비용 한도를 조직 단위로 관리하는 기능은 아직 없다.

메시지·실행 상태·이벤트·문서·자료 연결을 영속 저장한다. 프로젝트/실행/결과물 테이블은 기존 DB에 추가하며 기존 대화·파일은 삭제하지 않는다. 대화 삭제 시 연결 결과물과 실행 기록도 정리한다. 진행 중 대화·첨부 파일은 작업을 중지한 뒤 삭제할 수 있다.

## 모델 연결과 데이터 경로

사용자가 기존 개인용 DeepInfra 키 사용을 명시적으로 허용했다. 시연 서버의 비공개 `.env`에서 MODEL_API_KEY, MODEL_BASE_URL, MODEL_NAME을 관리한다. 개인 대화·기억은 이관하지 않았다. 키는 브라우저·로그·소스·Docker 이미지에 넣지 않는다. 현재 모델은 deepseek-ai/DeepSeek-V4.1-Flash-1017이다.

모델 요청에는 최근 최대 40개 메시지, 프로젝트 지침, 선택한 첨부 텍스트, 최근 문서 일부가 포함된다. 대화/자료는 사용자 요청에 따라 DeepInfra로 전송된다. 프로젝트는 권한 범위를 바꾸지 않으며 외부 도구·셸·호스트 파일시스템 접근은 제공하지 않는다. 실행 시작과 모델 출력 반영 시 계정 활성·승인 상태를 검사한다.

기관 내부망의 모델로 바꿀 때는 API 주소·키·모델 설정을 교체하고 스트리밍·도구 호출·한국어 품질을 다시 검증한다. 인증·모델·저장소의 내부망 운영 및 기관별 적용은 파일럿에서 검증한다.

## 검증

- 전체 자동 테스트 67개 통과, JS 문법·공백 검사 통과.
- 제공자의 nullable 스트림 필드와 잘린 스트림이 정상 완료로 표시되지 않음을 검증했다.
- 소유권·승인, 문서 버전·다운로드, 질문 후 재개, 중간 텍스트 개입, 취소, 중복 실행·경쟁 요청, 서버 복구를 합성 데이터로 검증했다.
- 실제 DeepInfra 호출로 프로젝트 지침·첨부 자료·문서 도구·미리보기 API·다운로드를 운영 DB와 분리한 임시 DB에서 검증했다. 시험 데이터는 종료 후 제거했다.
- 로컬 브라우저에서 합성 제공자로 프로젝트 생성 → 요청 → 진행 → 문서 패널 → 새로고침 후 복원을 확인했다.

실제 모델 검증 스크립트: scripts/probe_work.py. 배포 컨테이너에서 실행하며 소액 API 비용이 발생한다. 결과 본문·키를 출력하지 않는다. 새 기능의 장시간 부하·실제 휴대폰 키보드·운영 재부팅은 아직 검증하지 않았다.
